YASMIN — gotowy pakiet strony

ZAWARTOŚĆ:
- index.html — główna strona
- 404.html — strona błędu
- robots.txt — plik dla wyszukiwarek
- assets/images/ — wszystkie zdjęcia strony

CLOUDFLARE PAGES:
1. Wejdź na https://dash.cloudflare.com/
2. Workers & Pages -> Create application -> Pages -> Direct Upload.
3. Przeciągnij cały folder „yasmin-site” albo ZIP.
4. Nazwij projekt np. „yasmin-tarnow”.
5. Kliknij Deploy.
6. Dostaniesz adres np. yasmin-tarnow.pages.dev.

DOMENA:
1. W projekcie Pages -> Custom domains.
2. Set up a custom domain.
3. Wpisz kupioną domenę.
4. Ustaw DNS zgodnie z instrukcją Cloudflare.

WAŻNE:
- Formularz rezerwacji jest teraz demonstracyjny.
- Żeby naprawdę wysyłał maila i blokował termin, trzeba podpiąć backend/funkcję i pocztę.
- Linki FB/IG warto później podmienić na dokładne profile właściciela.
